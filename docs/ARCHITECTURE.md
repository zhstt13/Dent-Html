# Dent-Html Architecture

## Project Goal
Structured dental HTML study project with separated sections for easier debugging and future expansion.

## Planned Structure

- index.html
  - Global tokens
  - Header
  - Hero
  - Navigation
  - Content sections
  - Interactive components
  - Responsive rules

- sections/
  - Detailed documentation for each module

- assets/
  - Images
  - Icons
  - Fonts

## Debug Rule
Every major UI block should have:
- Clear comment boundaries
- Independent responsibility
- Documented dependencies
- Minimal cross-section coupling
